# Fast-MEGAHIT

**Fast-MEGAHIT** is an automated, fidelity-preserving pipeline for metagenomic assembly. It replaces traditional heuristic k-mer selection with a **CRITIC-based multi-objective optimization framework**, dynamically selecting the optimal k-mer list by analyzing the statistical properties of the k-mer frequency spectrum.

## 🌟 Key Features

- **Two-Component Mixture Modeling**: Robustly separates sequencing errors (Geometric distribution) from genuine biological signals (Normal distribution), with native support for **bimodal signals** (Dominant + Rare species).
- **PESC (Posterior-Expected Soft-Counting)**: A continuous soft-boundary innovation that eliminates step-function artifacts in effective k-mer counting, preserving subtle distributional shifts.
- **CRITIC-Inspired Adaptive Cutoff**: Replaces fixed posterior thresholds with a data-driven, gradient-based contrast analysis for robust error filtering.
- **Multi-Objective K-mer Selection**: Evaluates candidate k-values across 4 dimensions: *Node Retention*, *Error Mass*, *Species Resolution*, and *Cutoff Sharpness*.
- **Fully Automated End-to-End Pipeline**: Seamlessly integrates preprocessing, multi-k KMC counting, adaptive partitioning, and MEGAHIT assembly in a single Bash script.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/22han/Fast-MEGAHIT.git
cd Fast-MEGAHIT
```
### 2. Environment Setup
The pipeline requires two isolated Conda environments. The `full_pipeline.sh` script will  automatically switch between them during execution, so you only need to create them once.

```bash
# 1. Create environment for KMC (ultra-fast k-mer counting)
conda create -n kmc_env -c bioconda kmc -y

# 2. Create environment for Python pipeline (requires Python >= 3.9)
conda create -n vs2 python=3.10 -y
conda activate vs2
pip install numpy scipy pandas matplotlib tqdm
conda deactivate
```

## Quick Test (No External Data Required)
```bash
Run the full pipeline (it will automatically skip preprocessing and jump to KMC)
bash full_pipeline.sh .
```

## 📂 Output Structure

After a successful run, the working directory will contain the following structured outputs for each sample (e.g., `sample`):

- **`sampleclean_1.fastq` / `sampleclean_2_rc.fastq`**: Preprocessed, reverse-complemented reads ready for assembly.
- **`sample_kmer/`**: Directory containing KMC histogram outputs (`k21_spectrum.txt`, `k23_spectrum.txt`, etc.) for all evaluated k-values.
- **`sample_k_custom/`**: **Core Algorithm Output**. Contains the CRITIC optimization results:
  - `kmer_results_custom_selected_ks.txt`: The final optimal k-mer list (e.g., `K_LIST=[33, 47, 75, 79, 101]`).
  - `kmer_results_custom_metrics.csv`: Comprehensive statistical metrics for all evaluated k-values.
  - `kmer_results_custom_diagnosis.png`: A publication-ready **Results Figure** displaying the `soft_effective_diff` profile, change-point partitions, and selected k-values, allowing reviewers to intuitively grasp the method's core mechanism.
- **`sample_oli_custom/`**: **Final Assembly Output**. Contains the *de novo* assembly results generated by MEGAHIT using the dynamically optimized k-mer list. The most critical file for downstream analysis is **`final.contigs.fa`**, which represents the highest-quality contigs reconstructed through the multi-k iterative strategy.
