# Fast-MEGAHIT

Data-driven adaptive k-mer selection framework via Posterior-Expected Soft Counting and Spectral Partitioning for viral metagenome assembly.

## Quick Start

### 1. Clone and Install
```bash
git clone https://github.com/22han/Fast-MEGAHIT.git
cd Fast-MEGAHIT
pip install -r requirements.txt
```

### 2. Run the Pipeline with One Command
```bash
chmod +x full_pipeline.sh
./full_pipeline.sh /path/to/spectrum_directory
```
- `spectrum_directory` – Directory containing the k-mer spectrum files (e.g., generated by KmerLight, ntCard, or KMC).

### 3. Requirements
- Python ≥ 3.8
- Dependencies: `numpy`, `scipy`, `pandas`, `matplotlib`, `tqdm` (installed via `requirements.txt`)
- Memory: ~4 GB for standard virome datasets.
- CPU: Multi-core recommended.
